# Blue Sky — Calendrier Para

Page d'assistance de l'application iOS **Blue Sky — Calendrier Para**.

Blue Sky regroupe les calendriers des principaux centres de parachutisme en France : stages PAC, AFF, boogies, animations, compétitions et événements spéciaux.
